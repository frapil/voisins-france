# Les voisins de la France 🇫🇷

Un petit jeu web pour réviser les **8 pays limitrophes de la France** (en Europe) : Belgique, Luxembourg, Allemagne, Suisse, Italie, Monaco, Andorre, Espagne.

## Règles

- Un nom de pays s'affiche : il faut **cliquer dessus** sur la carte d'Europe.
- Un **minuteur** tourne (3 niveaux : 30 s, 20 s ou 10 s).
- **3 essais** par pays. Chaque erreur coûte **−25 pts**, et le jeu indique quel pays a été cliqué.
- Bonne réponse : **+100 pts** + bonus de rapidité.
- Après 3 erreurs ou à la fin du temps, le bon pays clignote sur la carte.
- Bouton **📖 Réviser** : la carte avec les 8 voisins nommés.
- Record enregistré par niveau (dans le navigateur).

Fonctionne sur ordinateur, tablette et téléphone.

## Jouer

Site statique, sans dépendance : ouvrez `index.html` dans un navigateur, ou publiez le dépôt avec GitHub Pages
(Settings → Pages → Branch `main`, dossier `/ (root)`).

Carte : Natural Earth (domaine public), via `world-atlas`.
